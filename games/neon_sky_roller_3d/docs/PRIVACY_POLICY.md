# Privacy Policy — Neon Sky Roller 3D

**Last updated:** 2026-11-13  
**Developer:** dhayalram  
**App:** Neon Sky Roller 3D (`com.dhayalram.neonskyroller3d`)

## Summary

Neon Sky Roller 3D is a single-player offline game. Progress (levels, gems, stars, skins, daily streak) is stored **only on your device**. This build does **not** collect personal information, does **not** require an account, and does **not** include ads or analytics SDKs.

## Data we store on device

| Data | Purpose | Leaves device? |
|---|---|---|
| Game progress (level, XP, gems, stars, unlocked skins) | Gameplay / retention | No |
| Daily mission / login streak timestamps | Daily gift & mission | No |

Stored via the engine’s local user data (`user://` save file). Uninstalling the app deletes this data (unless you use Android backup — this app does not request backup of sensitive data beyond normal app data).

## Data we do not collect

- Name, email, phone, or account credentials  
- Precise or approximate location  
- Contacts, photos, microphone, camera  
- Advertising ID / tracking for ads  
- Analytics or crash-reporting identifiers (none bundled in this version)

## Permissions

- **Vibrate** — optional haptic feedback during play. Not used to identify you.

No `INTERNET` permission is declared for the current release build.

## Children

The game is suitable for general audiences and does not knowingly collect personal data from children. Because no personal data is collected, COPPA “collection” obligations for this build are not triggered. If future versions add online services, this policy will be updated before those features ship.

## Third parties

None in the current build (no ads, no analytics, no social login).

## Changes

If we add online features (cloud save, ads, analytics), we will update this policy and the Play Console Data safety form **before** shipping that version, and bump the app version accordingly.
